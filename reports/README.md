# Verified results

This directory is reserved for aggregate, reproducible benchmark results.
Numbers must be generated by the checked-in pipeline on the documented frozen
well split. Do not add manually estimated metrics or confidential observations.

The comparison table will be populated after the real-data runs:

### Three-class benchmark: 24 held-out wells, 266,222 rows

| Model | Accuracy | Macro F1 | Balanced accuracy | NLL | ECE |
|---|---:|---:|---:|---:|---:|
| Referenced XGBoost repository (author-reported, different holdout) | 0.9300 | 0.8600 | not reported | not reported | not reported |
| Our XGBoost | 0.9369 | **0.8694** | 0.8422 | 0.1985 | 0.0211 |
| Deterministic 1D U-Net | 0.9076 | 0.8321 | 0.8529 | 0.2514 | **0.0038** |
| Probabilistic 1D U-Net | 0.9237 | 0.8458 | **0.8700** | 0.2326 | 0.0194 |
| Validation-selected ensemble | **0.9377** | 0.8679 | 0.8632 | **0.1883** | 0.0172 |

The referenced result is not an independently reproduced score and uses a
different random 20% well holdout, so the table is contextual rather than a
strict paired leaderboard. Our three models and ensemble use one identical
frozen split. The ensemble weight (40% XGBoost, 60% probabilistic U-Net) was
chosen on validation wells, not the test wells.

The XGBoost model has the best test macro F1. The ensemble has the best
accuracy and NLL. The probabilistic U-Net has the best balanced accuracy,
showing stronger equal-class recall despite lower overall accuracy.

## Harness verification

The public LAS archive was converted successfully and audited:

- 1,431,383 labelled depth samples;
- 118 wells;
- all 12 FORCE lithofacies codes;
- frozen split: 82 training, 18 validation and 18 test wells;
- no well overlap and all classes represented in training.

A dependency-light diagonal Gaussian classifier was run only as an end-to-end
sanity check on the 18 untouched test wells (259,860 rows): macro F1 0.1345,
balanced accuracy 0.2583 and weighted F1 0.4813. This deliberately weak result
is **not** a competitive benchmark; it confirms that the loader, grouped split,
train-only preprocessing and metric path execute on the real data.

See `dataset_audit.json`, `frozen_well_split.json` and
`sanity_gaussian_metrics.json`.
